# Block Busters — downloadable browser test

Download **block-busters-browser.zip**, extract it, and open the extracted
**Block-Busters** folder in VS Code. You need Node.js18 or newer.

Run this in VS Code's terminal:

```sh
npm start
```

Open the address printed in the terminal. No npm packages or Godot installation
are needed to play. Keep the terminal open. Do not open the HTML with file://.
The archive includes the complete original source and the prebuilt browser game.
For editing and rebuilding, see START_HERE.md in the extracted project.

The game is an endless offline brick breaker with local high scores.
This browser test does not install on Android; it runs in a modern browser.
