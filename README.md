# Block Busters — endless block puzzle (v1.1.0)

[Download the corrected browser-ready ZIP](https://github.com/games-trishool/Block-Busters/raw/refs/heads/downloads/block-busters-puzzle-browser.zip)

The corrected game is an **8×8 block-placement puzzle**: drag colorful square
pieces onto a purple board, complete rows or columns, and keep making space.
Three pieces per hand; endless offline play, combos and local best scores.
This replaces the earlier incorrect paddle-and-ball prototype.

## Run in VS Code

1. Stop any older running game server with **Ctrl+C** in its terminal.
2. Download and extract the new ZIP into a **new folder**.
3. Open the extracted **Block-Busters** folder in VS Code.
4. With Node.js18+ installed, run:

```sh
npm start
```

Open the address printed in the terminal. No npm install or Godot installation
is needed to play the included browser build. Drag a piece onto the grid, or
click a piece and then a board cell to place its top-left corner.
The archive includes the original Godot source, browser build and START_HERE.md.
